A clone of [Neofetch](http://github.com/dylanaraps/neofetch) written in Rust just like [Freshfetch](https://github.com/K4rakara/freshfetch), but this one is unique as it is dedicated to cheese, bcz i want to cheese.

### Prerequisite
- Rust and Cargo

### Installation
- `git clone `https://github.com/sakg-dev/cheesefetch.git`
- `cd cheesefetch/src`
- `cargo run`
Rn you cannot build it as it looks for ascii asset with relative path and if it is executed from smwhere else than src directory, it will throw err that file wasn't found
